# 南极科考态势大屏

基于 OpenLayers + proj4 的南极科考态势大屏（单文件 HTML 应用），采用 EPSG:3031 极射立体投影，接入 NASA GIBS 极地原生瓦片服务。

## 功能特性

- **极射立体投影底图**：EPSG:3031 + NASA GIBS 实时影像（蓝 Marble / 地表反照率等），圆形雷达式取景，平移边界约束不露黑底
- **全部科考站数据**：内置 55 座科考站（常年站 / 夏季站），点击站点查看详情（国家、建站年份、研究方向、简介），高亮光环标注
- **科考站列表**：搜索筛选、点击定位飞行到站点、支持 CSV / GeoJSON 下载
- **专题图层**：Quantarctica 风格数据叠加（冰盖与冰川、海洋与海冰、大气环境），可独立显隐
- **矢量数据面板**：图标触发的悬浮面板，加载 GeoJSON 矢量要素
- **数据统计卡**：站点总数、常驻/夏季占比、国家数、中国站点、内陆深冰盖站等实时统计
- **态势交互**：悬停读取投影坐标与经纬度、雷达扫掠动效、北京时间实时时钟

## 技术栈

| 组件 | 说明 |
|------|------|
| OpenLayers 10.4.0 | 地图引擎（CDN 引入，无需构建） |
| proj4 2.15.0 | EPSG:3031 投影定义 |
| NASA GIBS | 极地瓦片影像与专题图层 |
| 原生 HTML / CSS / JS | 单文件实现，无框架依赖 |

## 快速开始

直接用浏览器打开 `antarctic-ol-proj4.html` 即可，无需安装依赖或启动服务。

> 建议通过本地静态服务器访问（如 `npx serve` 或 VS Code Live Server），以保证 CDN 资源与瓦片加载稳定。

## 数据说明

- 专题图层取 2025-01-15（南半球盛夏）合成影像，半透明叠加于底图之上
- 科考站数据整理自公开资料，坐标为 WGS84 经纬度，渲染时经 proj4 转换到 EPSG:3031
